# God Games: The Game

A text-based adventure game based on the song "God Games" from Epic: The Musical. Players navigate interconnected rooms, interact with characters and events, engage in combat and dialogue, eventually leading up to a boss fight (if you survive long enough, that is).

**Features:**
- **Room Navigation:** Explore interconnected rooms with unique descriptions, interactions, and events.
- **Player Stats:** Track player attributes and use stat checks to determine outcomes.
- **Combat System:** Encounter enemies and bosses through combat-based challenges.
- **Randomized Events:** Experience variable encounters and outcomes during gameplay.

**Technical Highlights:** Uses functions, data structures, and a vector of structs to organize room states, navigation, encounters, and room-specific interactions.
